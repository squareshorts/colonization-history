# Colonization-history v10: strict carrier-identifiability and recovery bounds

**Computational and analytic extension, 7 November 2026.** No new bacterial experiments. Previously released version 1.1.0 and its Zenodo DOI remain unchanged. This addition is designed for independent execution after the v9 critical test.

## Contents

- `analysis/generality_attrition_v10.py` provides the general scalar-output theorem stress tests, sharp missing-data intervals, kinetic challenge simulations, and calibrated fifth-carrier interval computations.
- `tests/test_v10.py` validates algebra, exact sharpness and interval coverage on arbitrary missing-outcome patterns, recovery controls, two observation laws and calibration failure cases.
- `results/v10_summary.json` plus three CSVs hold all run summaries and 300 complete synthetic holdout trials.
- `figures/` has three figures generated by the script.
- `REPORT_V10.md` gives full methods, results, caveats and validated primary-source citations.

## Reproduce

Run from `extensions/v10` or this directory, with Python 3.10+ and NumPy, SciPy, Matplotlib installed:

    python analysis/generality_attrition_v10.py --trials 300 --studies 1500
    python -m unittest discover -s tests -v

The code uses explicit deterministic seeds. Results are synthetic and not empirical effect-size estimates. The general readout reparameterization and missing-data bounds are established mathematical tools; novelty is in their combined interpretation for the colonization-history carrier-discrimination problem.
