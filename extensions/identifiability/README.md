# Six-arm contrast identity

Given independently estimated counterfactual arm expectations F(0), F(2), F(3), F(4), F(12), and F(15), this algebra produces an exact **ordered** decomposition (nonlinear outcomes permitted). It is not a proof that selective initial-state erasures are biologically feasible, and it does not infer all symmetric Shapley effects from six arms.
